# 云进销存 · 用户手册

> 版本：v0.24 · 适用：单机版 / 私有部署 / SaaS 租户
> 本手册与系统内置的「使用手册」页（登录后右上角 **?** → 使用手册）内容同源，可打印发给客户。

## 1. 系统是什么

面向单店/单仓小微商户的进销存系统：单文件部署、开箱即用。覆盖商品档案、采购销售、库存批次、盘点差异、应收应付、报表看板、多用户权限、打印票据等完整闭环。

- 技术形态：一个 `jxc.exe`（Windows）或 `jxc`（Linux），数据在程序目录的 `data/` 下，**拷贝目录即迁移**
- 访问方式：浏览器打开 `http://服务器IP:8080`，建议 Chrome / Edge

## 2. 3 分钟快速上手

新账套按这个顺序配置，后面开单才不会卡：

| 步骤 | 位置 | 做什么 |
|---|---|---|
| ① 建商品 | 基础档案 → 商品档案 | 手工逐个建，或「批量导入」下载模板填好上传（编码必填，可带条码/PLU/多档价位） |
| ② 录期初 | 基础档案 → 期初库存 | 录入上架数量与成本，决定库存总值与毛利基数 |
| ③ 建往来 | 基础档案 → 供应商 / 客户 | 有欠账的客户把期初应收录在这里 |
| ④ 开单 | 采购销售 → 销售出库 | 选客户、加商品、确认生效；库存自动扣减、应收自动累计 |

想先看效果：登录页点「**选个行业一键体验**」，可选五金建材 / 便利店 / 生鲜果蔬 / 快消批发四套演示数据（含两个月自洽单据）。

> ⚠️ 重置演示数据会**清空当前账套**，正式数据请先在「其他设置 → 数据备份」手动备份。

## 3. 开单与单据状态

所有单据共用一套状态机：

```
草稿 ──确认──▶ 生效 ──作废──▶ 已作废（库存/欠款自动回冲）
```

- **草稿**：随便改，不影响库存和往来账
- **生效**：库存、成本、应收应付同时落账
- **作废**：反向流水回冲，单据留档可查，账不会乱
- **改不了已生效的单**：只能作废重开，这是刻意设计，保证流水可对账

不占库存的单据：采购订单、报价单（只做记录和跟单）。移库单只改货位分布、不动总量成本。

开单提速：

- 商品行直接扫码：条码 / 电子秤标签码都支持，同商品重复扫码自动累加
- 开单页底部显示本类型最近 8 张单据，点击定位
- 单价默认带出商品价，改价不影响档案

## 4. 库存、批次与货位

- 库存 = 期初 + 入库 − 出库，全部由流水重放得出，**不手工维护**
- 成本方式二选一：移动加权平均（通用） / FIFO（强制批次，适合食品药品）
- 批次商品入库要录批次与到期日，库存查询可展开批次明细，临期有预警
- 负库存默认禁止（错误码 2004），确有需要可在其他设置放开
- 安全库存：低于该值在首页与库存查询标红
- 货位：商品可设默认货位，出库按默认货位优先分配、不够跨货位拆流水；货位容量支持按数量/体积/重量三种计量，超容可只提醒也可硬拦截（2005）
- 移库单在货架间搬货，不动金额；删货位前必须先清空该货位库存

## 5. 盘点与差异处理

1. 两种盘法：**全仓盘点**（按商品总量）/ **按货架盘点**（逐架盘，可跨货架一次提交）
2. 提交后记录全部已盘行（含账实相符）+ 账面快照
3. 差异表可打印、可导出 CSV（Excel 直开）
4. 差异超阈值（差异率默认 10%，可配差异金额）→ 单据转**待审批**，不调账；主管（system 权限）通过后才生效，驳回则整单作废
5. 按**差异项复盘**：只盘上次有差异的商品，自动生成关联初盘的新盘点单

> 盘亏到 0 的商品复盘时会自动补行；老版本（无账面快照）的盘点单会提示重盘。

## 6. 打印与票据

| 类型 | 用途 | 说明 |
|---|---|---|
| A4 单据 | 存档、客户签收 | 完整明细 + 大写金额 + 签收栏 |
| 58mm 小票 | 热敏小票机 | 浏览器打印（Ctrl+P），建议关掉页眉页脚、边距选默认 |
| 盘点差异表 | 盘点结果 | 可打印、可导出 CSV |

打印模板（其他设置 → 打印模板）：

- 上传店头 Logo（自动压缩）、店名/电话/地址随模板带出
- 字段显隐开关：单价/金额/客户/批次等；**把金额关掉就是一张送货单**
- 改完可「预览小票效果」直接看最近一张单据的打印效果

散称商品：电子秤标签码直接扫进开单页。内置顶尖（13/18 位）、大华、寺冈码制，商品档案填 PLU 即可；其他品牌在「其他设置 → 秤码规则」加规则并在线测试。

## 7. 资金与报表

- **应收应付**：按单据实时聚合；收款单/付款单冲抵欠款，作废回滚
- **进销存汇总**：按流水重放，期末数永远等于库存查询结果
- **销售毛利**：按单据明细 × 结转成本
- **首页看板**：今日销售/毛利/单据、库存总值、应收应付、14 天趋势、最近单据、库存与货位预警

对不上账的排查顺序：单据查询（有无未生效/已作废）→ 库存流水 → 盘点盘平（差异留痕）。

## 8. 多人使用与权限

- 服务端装一台，其他人浏览器访问 `http://服务器IP:8080`，各用各的账号
- 权限四层：菜单可见 / 页面可进 / 接口可调 / 单据级；角色改完即时生效，不用重登
- 操作日志记录登录与所有变更（密码脱敏），可按人/动作筛选
- 公网访问**务必配 HTTPS**（Caddy 反向代理，见 README 部署章节），HTTP 下密码是明文

## 9. 数据、备份与迁移

- 全部数据在程序目录 `data/`（SQLite 单文件）
- 每天首次启动自动备份到 `data/backups/`；手动备份与下载在「其他设置 → 数据备份」
- 换机迁移 = 整个目录拷贝到新机器
- 以 Windows 服务运行时，日志在 `data/logs/jxc-YYYY-MM-DD.log`（按天，保留 14 天）

## 10. 授权与订阅

**单机 / 私有部署**：运行 `jxc.exe -machine-code` 获取机器码发给服务商 → 收到 `license.key` → 「其他设置 → 授权信息」导入，即时生效。未授权全功能试用 30 天；过期后**只读**（可查看/导出，不能改）。

**SaaS 租户**：注册开户送 14 天试用（2 用户/100 商品）；「订阅与计费」页查看套餐/账单/续费。到期只读、续费即恢复；用户数超套餐会拦截（5105）。

## 11. 常见问题

**Q：忘记管理员密码？**
让有 system 权限的账号在「用户与角色」重置；唯一管理员且回忆不起时，用备份库找回或联系服务商。

**Q：库存和实际对不上？**
库存流水核对有无漏录，确认后用盘点单盘平，差异留痕可追溯。

**Q：单据开错了能改吗？**
草稿可改；已生效的只能作废重开（自动回冲，账不乱）。

**Q：点打印没反应 / 版式错位？**
打印对话框里纸张选 58mm（小票）或 A4、边距最小或默认、关「页眉页脚」；用 Chrome / Edge。

**Q：提示授权/订阅过期？**
单机导入新 license.key；SaaS 去订阅页续费。到期只读、数据不丢。

**Q：升级后页面还是旧的？**
正常刷新即可（index.html 已设不缓存）；仍异常就 Ctrl+F5 强刷。

**Q：扫码没反应？**
确认商品档案有条码/PLU，光标在商品输入框；秤码需有对应品牌规则。

**Q：能上云服务器吗？**
可以：跑 jxc.exe（或注册服务），前置 Caddy 做 HTTPS，见 README「HTTPS 部署」。

## 12. 小技巧

- 列表页搜索框回车即查
- 单据查询支持 URL 直达：`/doc-list?doc_type=sales_out&keyword=XXX`

- 首页在「还没开过单」时会显示上手提示条，开过单自动消失
