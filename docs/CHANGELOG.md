## v0.22.0 — 2026-11-05（HTTPS：Caddy 反向代理部署）
- 定位：**HTTPS 由前置代理终结，应用只讲 HTTP 且只监听回环地址**，不在二进制内做 TLS（内网自签证书需逐台客户端信任，维护成本高于收益，暂不做）
- 应用侧新增 `JXC_TRUSTED_PROXIES`（默认 `127.0.0.1,::1`，逗号分隔 IP/CIDR，`none` 表示全不信任）：仅信任来自该列表的 `X-Forwarded-For/Proto`，操作日志记录真实客户端 IP，同时外部无法伪造来源 IP（实测：可信时记为 `203.0.113.9`，`none` 时记为 TCP 对端 `127.0.0.1`）
- 新增 `SecurityHeaders` 中间件：统一 `X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: same-origin`；识别到 HTTPS（直连 TLS 或 `X-Forwarded-Proto: https`）才下发 HSTS `max-age=31536000`，避免单机 HTTP 部署被浏览器锁死在 HTTPS 上
- 显式调用 `SetTrustedProxies`：消除 Gin 默认「信任所有代理」的告警与伪造风险；配置非法时回退为仅信任回环并打印提示
- 新增 `deploy/Caddyfile`：域名自动证书（Let's Encrypt 自动申请续期）+ gzip/zstd + API `no-store` + 访问日志滚动；内含「内网 `tls internal` 自签」与「已有 Nginx 复用 443」两段注释模板
- 新增 `deploy/jxc.service`：systemd 单元（环境变量、自动重启、`ReadWritePaths` 数据目录、`NoNewPrivileges` 等基础加固）
- README 新增「HTTPS 部署（Caddy 反向代理）」章节：拓扑、域名/Windows/内网三种落地路径、环境变量表、验收命令与常见故障（证书申请失败、接口 404、日志全是 127.0.0.1、导入 413）
- 启动日志增加代理信任来源与「对外请经 Caddy 走 HTTPS」提示

### 租户数据隔离（插件真正激活）
- 之前 `tenant_id` 字段与 GORM 租户插件虽已就绪，但服务层从不把请求上下文传给数据库，隔离实际是空的；本次把 **ctx 全线打通**：所有 service 方法接收 `context.Context`，统一经 `s.db(ctx)`（= `gorm.DB.WithContext(ctx)`）取句柄，插件自动追加 `tenant_id` 条件/填充 tenant_id
- 租户插件修复批量插入 panic（对 slice 逐元素填充）；0 号租户（单机版）也参与隔离，单机账号看不到任何 SaaS 租户数据
- 业务编码唯一约束从「全库唯一」下沉到「租户内唯一」（users.username / roles.name / products.code / suppliers.code / customers.code / warehouses.name / documents.doc_no / payments.doc_no），老库自动迁移（幂等）
- 系统设置改为按租户存储：新表 `tenant_settings`（主键 tenant_id+key），旧 settings 数据自动归入 0 号租户后改名备份；A 租户改店名不影响 B 租户
- 操作日志按租户归属（登录记录由 handler 回写 tenant_id）

## v0.16.0 — 2026-11-04（盘点差异审批流）

### 规则
- 「其他设置 → 业务规则」新增：**盘点差异需主管审批**（默认关）+ 两个阈值——差异率（|差异|÷账面数，默认 10%）与差异金额（按仓库均价估算，默认 0=不按金额）；命中**任一**阈值即触发
- 触发的盘点单确认后不调账，单据状态转 **`review`（待审批）**，`review_status=pending`，备注自动写入命中原因（如「劳保手套 差异率 30%>阈值10%」）；账面快照 `book_qty` 照常落库，差异表可正常打印/导出

- 待审批单也可由开单人**作废撤回**（未调账，无需回冲）
- 未超阈值的盘点单行为不变：确认即调账

### 权限与展示

- 单据查询：状态筛选/标签新增「待审批」（黄色）；列表行与详情均有「通过 / 驳回」按钮（仅主管可见）；详情展示审批状态与意见

- 审批调账路径与普通确认共用 `applyStocktakeAdjust`（差异一律基于 `book_qty` 快照计算），盘亏结转成本、盘盈按指定成本照常回填
